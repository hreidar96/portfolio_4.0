## Architecture

This is a **Next.js 16 App Router** portfolio site (single page, scroll-based navigation) with content managed in **Sanity**. The page is published in Icelandic (`/is`, default) and English (`/en`); `proxy.ts` redirects paths without a language prefix to `/is`.

### Key directories

- `app/[lang]/` — Root layout (fetches site settings, metadata, `<SanityLive />`, Visual Editing) and the single page (fetches the home page)
- `app/api/send/` — Contact form route (Resend API + React Email template in `email/`)
- `app/api/draft-mode/` — Enable/disable Draft Mode for the Studio's Presentation tool
- `components/` — UI components; section components receive Sanity query results as props
- `sanity/` — Sanity client, `defineLive` setup, image URL builder, GROQ queries (`lib/queries.ts`) and derived prop types
- `sanity.types.ts` — Generated by TypeGen; don't edit by hand
- `studio/` — Standalone Sanity Studio (own `package.json`), hosted at hreidarhallgrims.sanity.studio. Schema in `studio/schemaTypes/`
- `i18n.ts` — Supported languages; keep in sync with `studio/lib/languages.ts`
- `context/` — React Context for active section tracking and dark/light theme
- `lib/data.ts` — Section names and anchors for the header (labels come from Sanity)

### Content and localization

All site copy, images and the CV live in Sanity (project `7mzw821b`, dataset `production`). Text fields are internationalized arrays (`[{language, value}]`); queries resolve them with `field[language == $lang][0].value`, falling back to Icelandic. Home page and site settings are singletons with fixed IDs `homePage` and `settings`.

Visual Editing encodes invisible stega characters into strings. Use `stegaClean()` before comparing a string or using it as a URL, and fetch metadata with `stega: false`.

### State management

Two React Contexts wrap the app (in `app/[lang]/layout.tsx`):
- **ActiveSectionContext** — Tracks which section is in view for header nav highlighting. Has a `timeOfLastClick` guard that disables observer-based updates for 1 second after manual nav clicks.
- **ThemeContext** — Dark/light mode toggle, persisted to localStorage, respects system preference on first visit. Applies `"dark"` class to `<html>`.

### Scroll tracking pattern

Components call `useSectionInView("SectionName")` which returns a `ref`. That ref is placed on the section's root element. The hook uses `react-intersection-observer` with a configurable threshold (default 0.75) and updates the active section context when visible.

### Styling

Tailwind CSS 4 with dark mode via `"class"` strategy. Custom styles in `app/globals.css`. Framer Motion handles entrance animations and scroll-triggered effects on project cards.

### Environment variables

See `.env.example`.
- `NEXT_PUBLIC_SANITY_PROJECT_ID`, `NEXT_PUBLIC_SANITY_DATASET` — Sanity project
- `SANITY_API_READ_TOKEN` — Viewer token for Draft Mode / Visual Editing (server-side only)
- `RESEND_API_KEY` — Required for contact form email sending (server-side only)
